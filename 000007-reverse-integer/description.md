# 7. Reverse Integer

Дан знаковый 32-битный целый `x`. Верните `x` с перевёрнутыми цифрами. Если после переворота значение выходит за пределы диапазона знакового 32-битного целого `[-2^31, 2^31 - 1]`, верните `0`.

Считайте, что окружение не позволяет хранить 64-битные целые (знаковые или беззнаковые).

## Пример 1

Вход: x = 123

Выход: 321

## Пример 2

Вход: x = -123

Выход: -321

## Пример 3

Вход: x = 120

Выход: 21

## Ограничения

- -2^31 <= x <= 2^31 - 1
