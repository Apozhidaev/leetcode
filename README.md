# LeetCode

Решения задач с [leetcode.com](https://leetcode.com) на JavaScript, Python и Rust.

## Структура

Каждая задача в своей папке:

```
NNNNNN-problem-slug/
  description.md   # условие (на русском)
  explanation.md   # объяснение решения (по желанию)
  editorial.md     # ссылка на официальную статью LeetCode (по желанию)
  solution.js
  solution.py
  solution.rs
```
