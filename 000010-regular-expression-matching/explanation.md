# Объяснение решения

## Идея

Нужно проверить, совпадает ли **вся** строка `s` с шаблоном `p`, где:

- `.` — ровно один любой символ;
- `x*` — ноль или больше символов `x` подряд (для `.` — любых).

Жадный разбор «с начала» плохо подходит: из‑за `*` часто приходится отступать. Удобнее динамическое программирование по префиксам.

`dp[i][j] = true`, если префикс `s` длины `i` (`s[0..i)`) полностью совпадает с префиксом `p` длины `j` (`p[0..j)`).

Ответ задачи — `dp[m][n]`.

## База

- `dp[0][0] = true` — пустая строка совпадает с пустым шаблоном.
- Пустая строка может совпасть с непустым шаблоном только за счёт `*`, которые «съедают» ноль символов: `a*`, `a*b*`, `.*` и т.п.

  Для `j >= 2`, если `p[j - 1] == '*'`:

  ```text
  dp[0][j] = dp[0][j - 2]
  ```

  (пара `x*` ничего не берёт из строки).

## Переходы

Смотрим на последний символ шаблона `p[j - 1]`.

### 1. Обычная буква или `.`

Символ должен совпасть с `s[i - 1]` (для `.` — всегда), а предыдущие префиксы — тоже:

```text
dp[i][j] = dp[i - 1][j - 1]
           если p[j - 1] == '.' или p[j - 1] == s[i - 1]
```

Иначе `dp[i][j] = false`.

### 2. Звёздочка `*`

`*` относится к предыдущему элементу `p[j - 2]`. Два варианта:

**Ноль вхождений** — пара `x*` просто пропускается:

```text
dp[i][j] = dp[i][j - 2]
```

**Одно или больше** — текущий символ строки подходит под `p[j - 2]`, и тогда «остаток» строки без этого символа тоже должен совпадать с тем же шаблоном (звёздочка продолжает действовать):

```text
если p[j - 2] == '.' или p[j - 2] == s[i - 1]:
    dp[i][j] = dp[i][j] или dp[i - 1][j]
```

Итого для `*`:

```text
dp[i][j] = dp[i][j - 2]                          // ноль раз
        или (символ подходит и dp[i - 1][j])      // ещё один раз
```

## Пример

`s = "aab"`, `p = "c*a*b"`

1. `c*` → ноль раз → как пустой префикс шаблона.
2. `a*` → два `a`.
3. `b` → совпадает с последним символом.

`dp[3][5] = true`.

## Сложность

- Время: O(m · n)
- Память: O(m · n)

где `m = |s|`, `n = |p|`. При ограничениях до 20 этого достаточно.
