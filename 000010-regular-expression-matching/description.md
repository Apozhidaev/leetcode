# 10. Regular Expression Matching (Hard)

Даны строка `s` и шаблон `p`. Реализуйте сопоставление с регулярным выражением с поддержкой `.` и `*`:

- `.` — любой один символ
- `*` — ноль или более вхождений **предыдущего** элемента

Верните булево значение: покрывает ли совпадение **всю** входную строку (не частично).

## Пример 1

Вход: s = "aa", p = "a"

Выход: false

Пояснение: `"a"` не совпадает со всей строкой `"aa"`.

## Пример 2

Вход: s = "aa", p = "a*"

Выход: true

Пояснение: `*` означает ноль или более предыдущего элемента `'a'`. Повторив `'a'` один раз, получаем `"aa"`.

## Пример 3

Вход: s = "ab", p = ".*"

Выход: true

Пояснение: `".*"` означает «ноль или более (`*`) любых символов (`.`)».

## Ограничения

- 1 <= s.length <= 20
- 1 <= p.length <= 20
- `s` содержит только строчные английские буквы
- `p` содержит только строчные английские буквы, `.` и `*`
- Гарантируется, что перед каждым `*` есть валидный предыдущий символ для сопоставления
