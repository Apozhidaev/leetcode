# 14. Longest Common Prefix (Easy)

Напишите функцию, которая находит самую длинную общую приставку среди массива строк.

Если общей приставки нет, верните пустую строку `""`.

## Пример 1

Вход: strs = ["flower","flow","flight"]

Выход: "fl"

## Пример 2

Вход: strs = ["dog","racecar","car"]

Выход: ""

Пояснение: среди входных строк нет общей приставки.

## Ограничения

- 1 <= strs.length <= 200
- 0 <= strs[i].length <= 200
- `strs[i]` состоит только из строчных английских букв, если строка непустая
