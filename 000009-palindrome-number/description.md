# 9. Palindrome Number (Easy)

Дан целый `x`. Верните `true`, если `x` — палиндром, и `false` иначе.

## Пример 1

Вход: x = 121

Выход: true

Пояснение: 121 читается одинаково слева направо и справа налево.

## Пример 2

Вход: x = -121

Выход: false

Пояснение: Слева направо читается `-121`, справа налево — `121-`. Это не палиндром.

## Пример 3

Вход: x = 10

Выход: false

Пояснение: Справа налево получается `01`. Это не палиндром.

## Ограничения

- -2^31 <= x <= 2^31 - 1

## Дополнительно

Можете ли вы решить задачу без преобразования числа в строку?

## Подсказка 1

Осторожно с переполнением при перевороте целого числа.
