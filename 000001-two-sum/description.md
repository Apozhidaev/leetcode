# 1. Two Sum

Дан массив целых чисел `nums` и целое число `target`. Верните индексы двух чисел, сумма которых равна `target`.

Можно считать, что у каждого входа ровно одно решение, и один и тот же элемент нельзя использовать дважды.

Ответ можно вернуть в любом порядке.

## Пример 1

Вход: nums = [2,7,11,15], target = 9

Выход: [0,1]

Пояснение:

Сумма nums[0] и nums[1] равна 2 + 7 = 9, что совпадает с target. Поэтому возвращаются индексы [0, 1].

## Пример 2

Вход: nums = [3,2,4], target = 6

Выход: [1,2]

Пояснение:

Сумма nums[1] и nums[2] равна 2 + 4 = 6, что совпадает с target. Поэтому возвращаются индексы [1, 2].

## Пример 3

Вход: nums = [3,3], target = 6

Выход: [0,1]

Пояснение:

Сумма nums[0] и nums[1] равна 3 + 3 = 6, что совпадает с target. Поэтому возвращаются индексы [0, 1].

## Ограничения

- 2 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9
- -10^9 <= target <= 10^9
- Существует ровно один корректный ответ.
