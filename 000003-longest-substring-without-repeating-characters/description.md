# 3. Longest Substring Without Repeating Characters

Дана строка `s`. Найдите длину самой длинной подстроки без повторяющихся символов.

## Пример 1

Вход: s = "abcabcbb"

Выход: 3

Пояснение: Ответ — "abc", длина 3. Также подходят "bca" и "cab".

## Пример 2

Вход: s = "bbbbb"

Выход: 1

Пояснение: Ответ — "b", длина 1.

## Пример 3

Вход: s = "pwwkew"

Выход: 3

Пояснение: Ответ — "wke", длина 3.
Обратите внимание: ответ должен быть подстрокой; "pwke" — это подпоследовательность, а не подстрока.

## Ограничения

- 0 <= s.length <= 10^5
- `s` состоит из английских букв, цифр, символов и пробелов.

## Подсказка 1

Уникальных символов меньше 100. Можно проверять все подстроки длиной не больше 100 — это достаточно хорошее приближение.
